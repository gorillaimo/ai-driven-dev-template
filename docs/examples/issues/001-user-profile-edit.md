# サンプルissue: プロフィール編集機能

## 概要

- Issue: 作成後に記入
- 種別: Feature
- 優先度: Medium
- 担当: gorillaimo
- アプリ名: Example App
- 対象プラットフォーム: Next.js Web / Backend API

## 目的

ログイン中のユーザーが、自分のプロフィール表示名を変更できるようにする。

## 背景

現在はユーザー登録時に設定した表示名を後から変更できない。利用者が表示名を修正したい場合に運営側の対応が必要になっているため、ユーザー自身で編集できる画面とAPIを追加する。

## スコープ

- プロフィール編集画面を追加する。
- ログイン中ユーザーの現在の表示名を表示する。
- 表示名を更新するAPIを追加する。
- 表示名の入力バリデーションを追加する。
- 更新成功時に画面上で完了状態を表示する。
- 受け入れ条件に対応するテストを追加する。

## 非スコープ

- メールアドレス、パスワード、アイコン画像の変更は含めない。
- 管理者による他ユーザーのプロフィール編集は含めない。
- 通知メール送信は含めない。
- 表示名の重複禁止は含めない。

## 受け入れ条件

- [ ] ログイン中ユーザーがプロフィール編集画面を開ける。
- [ ] 現在の表示名が初期表示される。
- [ ] 1文字以上、40文字以下の表示名を保存できる。
- [ ] 空文字、40文字を超える表示名は保存できず、エラーが表示される。
- [ ] 未ログインユーザーはプロフィール編集APIを実行できない。
- [ ] 更新後に再表示しても新しい表示名が反映されている。

## 影響範囲

- Frontend: プロフィール編集画面、入力フォーム、エラー表示
- Backend: プロフィール取得・更新API
- Architecture: 既存構成を変更しない
- Infrastructure: なし
- API: プロフィール更新エンドポイント
- Auth: ログインユーザー本人のみ更新可能
- DB / Storage: ユーザー表示名
- Monitoring / Logging: APIエラーのログ出力
- Documents: 要件定義、設計、API仕様

## テスト観点

- 正常系: 有効な表示名で更新できる。
- 異常系: 空文字、長すぎる表示名で更新できない。
- 権限・認可: 未ログインユーザー、他ユーザーのプロフィール更新を拒否する。
- 境界値: 1文字、40文字、41文字の表示名を確認する。
- 回帰: 既存のログイン状態、ユーザー情報表示に影響がない。

## 実装メモ

AIエージェントは、実装前に `docs/system-context.md`、`docs/architecture.md`、既存の認証・ユーザー管理方針を確認する。API追加が必要な場合は、実装前に `docs/api/openapi.yaml` の更新方針を提示する。
